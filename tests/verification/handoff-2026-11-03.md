# Task handoff: OPPO acceptance, 2026-11-03

Physical device: OPPO PEUM00, Android 14. Isolated Debug app: `lifeos.md.tapilot.e2everify`. The tested integration was `89dae1a`, including PRs #29–#32. The installed production app and its data were retained.

## English attempt

1. Send a real Calculator task to calculate 23 × 7.
2. Bring Tapilot to the foreground while execution is underway. Device interaction pauses while the chat is open.
3. Select Take over. Automatic actions stop, saved task context remains visible, and Return to app / Continue task appear after acknowledgement.
4. Select Return to app. Calculator is restored with 23 visible. Manually clear it using AC.
5. Return to Tapilot and select Continue task. A new screen-check operation and fresh capture occur before any action.
6. The model connection times out after retries. This attempt is **not** counted as a successful continuation. Stop it through the UI; no task completion is claimed.

## Chinese continuation acceptance

1. Switch the app to Simplified Chinese and retry the original Calculator task.
2. Bring Tapilot forward and select the localized takeover control. Confirm the stopped acknowledgement and handoff buttons.
3. Select Return to app. Calculator shows the unfinished expression 23 ×.
4. Manually tap 7 and equals. The screen displays 23 × 7 = 161. These two taps are manual test actions, not agent actions.
5. Return to Tapilot and select Continue task.
6. The first fresh screen check sees a partially obscured transition frame and does not accept the result. The agent checks again, sees the complete expression and 161, and passes independent result verification.
7. The resumed task finishes successfully in 63 seconds. Its recorded execution steps are Query, Plan, Query; no Tap or other device action repeats the calculation. Native call counters also contain captures but no gesture calls.
8. Return to chat and verify the completed result is 23 × 7 = 161. No task remains running.

The earlier network failure and initial transition-frame obstruction remain recorded. This acceptance confirms one harmless Calculator handoff, not transaction-level idempotency in arbitrary apps. Fast app transitions can require an additional screen check. Interaction coordinates were selected from screenshots; a pre-existing production floating bubble was moved away from controls when necessary.
